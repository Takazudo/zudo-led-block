## CI のブラウザ確認 (Chrome の起動待ち)

以前、ドキュメントのジョブの「Framework check-browser」の手順が、開始から約 0.4 秒で `Error: Chrome page target was not available` と出て失敗することがありました。原因は `@takazudo/zudo-circuit-doc@0.3.0` の `lib/browser-smoke/chrome.js` が Chrome のページターゲットを 1 回しか読まないことでした。PR #67 で pnpm の patch (`patches/@takazudo__zudo-circuit-doc@0.3.0.patch`、`pnpm-workspace.yaml` の `patchedDependencies`) を入れ、`/json/list` を最大 10 秒まで待ち、Chrome が終了したらすぐ失敗するようにしました。失敗の無視や再実行の仕組みではありません。この patch は 0.3.0 専用で、上流が同じ修正を出したら外します (`ZUDO_DEPS_PINS.md`)。依存を更新するときは patch がまだ当たるかを確認してください。
