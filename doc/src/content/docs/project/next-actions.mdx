**現在の作業は [#87](https://github.com/Takazudo/zudo-led-block/issues/87) の0.8 mm rigid FR-4設計変更です。** 旧設計の注文作業をそのまま進める段階ではありません。透明PET/FPCとその供給元質問は現行候補・次作業から撤回しました。

1. A5外の新leaf正本とcontrollerを0.8 mmへ変更し、実stackup、全層GND実配線、両面mask開口と必要な保護領域を整えます。電源アダプタの光路・収まりへの影響も確認します。
2. ±0.1 mmの板厚公差、jack軸・端子・穴・nut/washer・支持・隣接module・ハーネス・工具アクセス・奥行で2HPを評価します。根拠が足りなければ0.8 mmの3HPへ進み、寸法不成立と資料不足を区別します。
3. 新leafを含むnative ERC/parity/DRC/未接続/refill/再生成保護、routing再現と全銅層・表裏mask Gerberを確認します。旧GND面を前提とした電源return/CV/LED干渉評価をやり直します。
4. 新板厚から機構・治具・CAD・製造入力を再生成します。旧治具PASSや注文ファイルのhashを付け替えて再利用しません。
5. 全層銅の遮光と未測定のFR-4半透明表現を分けたpreviewを生成し、manifest・選択・PCB・CAD・panelを同じrevisionへ揃えます。
6. 電気・機構の独立レビューとcurrent-head CIを通過し、repository policyを満たした統合PRをmainへmergeします。残作業中はdraftを維持します。
