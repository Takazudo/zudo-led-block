- **R4 基板リビジョン 2** (PR #37 `edf98c2`)。基板 `4453f818…628e`。レビューの改善 4 項目を反映し、厳しくする方向だけの PTH–配線 0.35 mm の規則 (`a7_pth_to_track`) と、その負の対照を追加。ゲート `PASS`、独立した再レビューでブロッキングの指摘なし。

- **R4 配置・配線、リビジョン 1** (PR #30 `eb8adeb`、2026-11-08)。基板 `ec810aec…` で A7 のゲートが `PASS` (ERC 0、パリティ 0、DRC 0、未接続 0、負の対照すべて検出)。設計ルールの差分はビア 0.5 / 0.2 mm と最小スルーホール径 0.2 mm で、JLCPCB の公開能力を根拠に記録。独立レビューは 1 回目で降圧とアナログ部の修正を求め、2 回目で承認。#19 は開いたままです。

## A5 の作業がどう引き継がれるか

A5 の「次の作業」は次のように扱います。A5 のファイルは変更しません。

| A5 の作業 | A7 での扱い |
|---|---|
| 制御基板の配置・配線を終える | A5 / A6 の 8.8 mm 基板ではなく、A7 の垂直な制御基板で完了 (R4、PR #30、デジタル検証のみ) |
| 電源ケーブルの実装を決める | 引き続き必要 ([#8](https://github.com/Takazudo/zudo-led-block/issues/8))。A7 の機構モデルでは、アダプタを 2.0 mm 前へ移し、PicoBlade の自由長 57 ± 3 mm (±3 は仮定) を要求。実物での確認が必要 |
| 機構の公差と造形 | A7 の機構モデルでは、ジャックの襟とトグルの回り止めをなくし、PMMA 裏の 0.5 mm ポケットで座りと回り止めを取る。基板は 2 個のジャックと印刷のスパインで支える (R2)。PETG での造形・保持力の確認は引き続き必要 |
| 完成回路で保護を再確認 | 引き続き必要 ([#10](https://github.com/Takazudo/zudo-led-block/issues/10))。電源・CV・起動の動作は A5 を維持 |
| 統合試作のリリース準備 | A7 の回路・基板・機構はデジタルでそろった。物理ゲートの解消が先。製造リリースと発注は現在の作業範囲外 |
| 実機の評価 | 引き続き必要 ([#10](https://github.com/Takazudo/zudo-led-block/issues/10)、[#13](https://github.com/Takazudo/zudo-led-block/issues/13)) |

部品証跡カタログでは、メーカー一次資料が取得できなかった項目や、販売店がホストする写し (MANUFACTURER_MIRROR) しか無い項目が `OPEN` のまま残っています。資料が入手できたら `circuit/WORKFLOW.md` の Workflow C に従い、事実を 1 件ずつ更新します。一括での格上げはしません。
