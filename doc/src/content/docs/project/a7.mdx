## A7 の方針 (2026-11-08 に採用)

| 項目 | 内容 |
|---|---|
| 前面 | 透明キャスト PMMA (高さ 128.5 mm、厚さ 2 mm) の光る文字と、正面向きの 3.5 mm CV ジャック 2 個 (IN と THRU)。裏面フロスト・正面平滑の見た目を維持 |
| 前面から外すもの | スイッチの穴、MODE の表示、ON / PGM / CV の表示 |
| モード切替 | 基板側の小さな設定スイッチ。取り付け前、またはモジュールを外した状態で操作する設定用 |
| ジャック | 直角のねじ付きジャック SOFNG PJ-324M (LCSC C22355739)。モノラル CV だけに使い、ステレオ機能は追加しない |
| 制御基板 | 前面に対して垂直に置き、奥行きを配線の場所として使う |
| 幅 | 2HP (9.8 mm) を優先、3HP (14.9 mm) を代替として採用。3HP は幅を広げれば解決すると決めつけず、別に確認する |
| 透明 LED 基板 | LED 部分だけ透明 PET FPC を検討。制御・電源・ジャックやスイッチの荷重はリジッド FR-4 に置く。A5 の FR-4 LED 基板を基準・予備として残す |
| 維持するもの | 奥行き 30 mm 目標 (PMMA 裏面から)、左右独立した 4 画素の RGB 2 列、共通の電流制限 LED 電源、受動の CV IN→THRU、MCU のピン割り当て、CV の変換、電源・起動の動作、工場実装と完成ケーブル |

透明 PET の回路フィルム、透明 PMMA の前面、半透明 PETG の拡散板は役割が違い、互いに置き換えられる材料ではありません。

## 機構モデルの結果 (デジタル、暫定)

出典は `engineering/a7/mechanical/README.md` と、生成された `layout.md`・`exports/<幅>/verification.json` です。CadQuery で作った固体モデルと寸法の積み上げで、試作や実測ではありません。

| 項目 | 結果 |
|---|---|
| 幅 | **3HP (中央、1.6 mm FR-4、端子未カット) を作業候補**とし、机上で成立。生成するアートワーク・支持体・CAD の標準は 3HP |
| 2HP | ジャックを 0.6 mm ずらし、0.8 mm FR-4、端子カット。公称ではすべて余裕があるが、最悪条件で端子側 −0.33 / 本体側 −0.15 mm で **未確定** (不成立ではない)。軸高さ (Q1) か端子カット長 (Q6) の証拠で再検討 |
| ジャック位置 | IN が Y 84.3、THRU が Y 99.3 (間隔 15.0 mm、A5 は 14.0)。表示の文字をジャックの間に置くため |
| ねじのかかり | PMMA 裏の 0.5 mm ポケットに両ジャックを座らせ、最悪でも 1.25 mm かかる。ポケットは回り止めも兼ねる。見え方と強度は未確認 (Q8) |
| 制御基板 | 外形は両方の幅で共通 (Y 48.5〜111.4 × Z 0.2〜16.4、1019 mm²。A5 は 554 mm²) |
| 奥行き | 光学部 (Z 17.4〜29.8) は A5 のまま。制御基板はその 1.0 mm 手前で終わる |
| 設定スイッチ | 基板の下端。操作部は Y 111.4 まで出て、モジュールを外して下から操作する。工具の通り道はモデル上で空いている (レールやケースはモデル化していない) |
| 電源アダプタ | A5 のアダプタを形を変えずに 2.0 mm 前へ。上キャップのねじは M2x16 から M2x18。締め付け荷重とボスの強度は未評価 |
| 電源ケーブル | アダプタ–制御基板の PicoBlade は自由長 **56 ± 3 mm** が必要 (±3 は仮定)。A5 の 50 ± 6 mm は入らない。配線も実測もしていない ([#8](https://github.com/Takazudo/zudo-led-block/issues/8)) |
| LED ハーネス | 50 mm の SH4 を R 2.5 以上で通す経路がある。LED D2 の光の約 2 % がハーネスにかかるという推定 (反射・拡散を含まない見積り) |
| 前面アートワーク | スイッチの穴、MODE、ON / PGM / CV の表示、A5 の Y65 穴を削除。IN と THRU をジャックの上に追加。裏面フロスト・透明文字は維持。注文用ファイルではない |

## 部品の変更案 (A5 の BOM との差分)

A7 の回路図 (PR #24) は A5 の制御基板の回路から **J1・J2・SW1 の 3 部品だけ** を差し替え、ほかの部品と接続は A5 のままです (差分チェックで他の接続変化は 0)。基板がまだ無く、ナット・電源ケーブル・LED 基板も未決定なので、**A7 の BOM は確定していません**。[部品表 (A5 BOM)](/docs/architecture/bom/) は A5 の記録のまま変えていません。

| 役割 | A5 | A7 の候補 | 状態 |
|---|---|---|---|
| CV IN / THRU ジャック (×2) | XKB PJ-3582-B (C500090) | SOFNG PJ-324M (C22355739)。[記録](/docs/components/records/a7-pj-324m/) | 資料はミラーのみ。軸高さは推定、ピン機能は推定 (要導通確認)、穴径は図面に無い |
| ジャックのナット | — | 付属の有無が不明 | M6x0.5 のナットが合うかは未確認 |
| モード切替 | Dailywell 1MS3T1B1M2QES-5 (C908270)、前面のトグル | C&K PCM13SMTR (C221842)、基板側の側面スライド。[記録](/docs/components/records/a7-pcm13smtr/) | 位置ごとの端子表 (ミラー) で選定。**JLC の在庫は 0** (2026-11-08)。代替候補は端子表が無い |
| 上キャップのねじ | M2x16 | M2x18 (機構モデル) | 締め付け荷重は未評価 |
| 電源ケーブル (PicoBlade) | 50 ± 6 mm | 自由長 56 ± 3 mm の要求 (±3 は仮定) | 未調達・未実測 (#8) |
| LED 基板 | 0.6 mm FR-4 ×2 | 透明 PET FPC を検討、FR-4 を予備 | JLC への質問は未送信 |

A7 の部品は `line-a7-` の行として部品カタログに登録しています。A5 の 30 型番 / 71 配置 / 81 点の集計には含めません。
