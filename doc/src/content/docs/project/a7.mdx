## A7 の方針 (2026-11-08 に採用)

| 項目 | 内容 |
|---|---|
| 前面 | 透明キャスト PMMA (高さ 128.5 mm、厚さ 2 mm) の光る文字と、正面向きの 3.5 mm CV ジャック 2 個 (IN と THRU)。裏面フロスト・正面平滑の見た目を維持 |
| 前面から外すもの | スイッチの穴、MODE の表示、ON / PGM / CV の表示 |
| モード切替 | 基板側の小さな設定スイッチ。取り付け前、またはモジュールを外した状態で操作する設定用 |
| ジャック | 直角のねじ付きジャック SOFNG PJ-324M (LCSC C22355739)。モノラル CV だけに使い、ステレオ機能は追加しない |
| 制御基板 | 前面に対して垂直に置き、奥行きを配線の場所として使う |
| 幅 | 2HP (9.8 mm) を優先、3HP (14.9 mm) を代替として採用。3HP は幅を広げれば解決すると決めつけず、別に確認する |
| 透明 LED 基板 | LED 部分だけ透明 PET FPC を検討。制御・電源・ジャックやスイッチの荷重はリジッド FR-4 に置く。A5 の FR-4 LED 基板を基準・予備として残す |
| 維持するもの | 奥行き 30 mm 目標 (PMMA 裏面から)、左右独立した 4 画素の RGB 2 列、共通の電流制限 LED 電源、受動の CV IN→THRU、MCU のピン割り当て、CV の変換、電源・起動の動作、工場実装と完成ケーブル |

透明 PET の回路フィルム、透明 PMMA の前面、半透明 PETG の拡散板は役割が違い、互いに置き換えられる材料ではありません。

## 部品の変更案 (A5 の BOM との差分)

A7 の回路図はまだ `main` に入っていないので、**A7 の BOM は確定していません**。下の表は R1 で選んだ候補で、[部品表 (A5 BOM)](/docs/architecture/bom/) は A5 の記録のまま変えていません。

| 役割 | A5 | A7 の候補 | 状態 |
|---|---|---|---|
| CV IN / THRU ジャック (×2) | XKB PJ-3582-B (C500090) | SOFNG PJ-324M (C22355739)。[記録](/docs/components/records/a7-pj-324m/) | 資料はミラーのみ。軸高さは推定、ピン機能は推定 (要導通確認)、穴径は図面に無い |
| ジャックのナット | — | 付属の有無が不明 | M6x0.5 のナットが合うかは未確認 |
| モード切替 | Dailywell 1MS3T1B1M2QES-5 (C908270)、前面のトグル | C&K PCM13SMTR (C221842)、基板側の側面スライド。[記録](/docs/components/records/a7-pcm13smtr/) | 位置ごとの端子表 (ミラー) で選定。**JLC の在庫は 0** (2026-11-08)。代替候補は端子表が無い |
| LED 基板 | 0.6 mm FR-4 ×2 | 透明 PET FPC を検討、FR-4 を予備 | JLC への質問は未送信 |

A7 の部品は `line-a7-` の行として部品カタログに登録しています。A5 の 30 型番 / 71 配置 / 81 点の集計には含めません。
