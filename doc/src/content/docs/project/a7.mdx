**A7は0.8 mm rigid FR-4への設計変更中です。** 2026-11-17 JSTのowner指示を、親 [#15](https://github.com/Takazudo/zudo-led-block/issues/15) と新しい子 [#87](https://github.com/Takazudo/zudo-led-block/issues/87) で追跡します。旧設計のデジタル完了・注文承認は、新設計の完了や製造releaseを意味しません。

[組立プレビュー](/docs/project/a7-preview/) · [次の作業](/docs/project/next-actions/)

## 採用した設計方針

透明PCBはrigid基板の代替と考えていましたが、実際には薄いflex PCBだったため、透明PET/FPC案を撤回しました。普通のFR-4基材のくすんだ半透明性を試します。透過率や拡散、実物の見え方は未測定です。

- LED leafとcontrollerを公称0.8 mmにします。板厚公差は±0.1 mmを評価に使い、実stackupと製造条件を照合します。
- 両面のソルダーレジストは必要箇所以外を開口します。配線・pad・via・必要な局所銅は残し、全層の広いGND面を撤去します。残すmaskと銅の位置・理由をGerberと照合します。
- 2HP（前面9.8 mm）を優先します。公差・配線・組立の成立根拠を確保できなければ3HP（14.9 mm）へ進みます。3HPでも0.8 mmとmask/copper方針は変わりません。
- 8個のRGB LED、左右各4個の独立2stream、共通の電流制限付きVLED、passive CV IN→THRU、MCU pin・CV伝達関数・modeを維持します。
- 前面高さ128.5 mm、cast PMMA 2 mm、奥行30 mm目標、工場実装と完成ケーブルを用いる組立方針を維持します。

## 検証と履歴の区別

旧0.6 mm leafはA5の不変資料です。新leafの正本をA5外に設け、controllerとともにnative検証・製造入力へ接続します。leaf積層は0.8×2＋bond 0.1＝1.70 mm nominalとなり、公差、支持、治具、光路、ハーネスとCADを再評価します。

旧controller 1.6 mmのnative/fixture PASS、[PR #82](https://github.com/Takazudo/zudo-led-block/pull/82) の承認、`order/2026-11-13/`の注文ファイルは旧identityに結び付く履歴です。新設計へ流用しません。今回の指示は設計方針の承認であり、発注や製造releaseではありません。

実物の透過性、熱、電気動作、組立、治具接触、実機収まりは別の物理作業です。[#8](https://github.com/Takazudo/zudo-led-block/issues/8)、[#10](https://github.com/Takazudo/zudo-led-block/issues/10)、LED timing [#13](https://github.com/Takazudo/zudo-led-block/issues/13) の残存条件を維持します。A5は不変、A6 [#7](https://github.com/Takazudo/zudo-led-block/issues/7) / draft [PR #14](https://github.com/Takazudo/zudo-led-block/pull/14) は保留です。

現在の証跡と再開手順は [継続記録](https://github.com/Takazudo/zudo-led-block/blob/main/engineering/a7/docs/continuation/continue-here.md)、[根拠索引](https://github.com/Takazudo/zudo-led-block/blob/main/engineering/a7/docs/continuation/evidence-index.md) を参照してください。
