## LED リーフ: FR-4 が標準、透明 PET は透明な支持板に貼る場合だけ機構上は成立 (デジタル)

出典は機構の比較が `engineering/a7/mechanical/README.md`、生成された `layout.md` と `layout.json` の `leaf_comparison`、`exports/3hp_pet/` (PR [#35](https://github.com/Takazudo/zudo-led-block/pull/35) `1b9d02d`)、電気の確認が `engineering/a7/verification/pet_leaf/` と `scripts/a7_pet_leaf_check.py` (PR [#42](https://github.com/Takazudo/zudo-led-block/pull/42) `355999a`) です。机上の比較で、試作や実測ではありません。FR-4 のリーフは置き換えません。

| 項目 | 結果 |
|---|---|
| 構成 | JLC の 1 層透明 FPC (0.14 mm) 2 枚を、透明な接着層 OCA (0.1 mm、推定) で厚さ 0.8 mm の透明 PC 支持板 (推定) の両面に貼る。合計 1.28 mm (FR-4 は 1.30 mm) で A5 のキャップの溝に入る |
| 位置 | LED・コネクタ・光の通り道・ハーネスの出口は 0.01 mm しか動かない。リーフの Z 範囲は変わらないので、0.5 mm のジャックのポケットと奥行き 30 mm は影響を受けない |
| 剛性 | FR-4 より 8〜37 倍柔らかい (材料の典型値、推定)。SH コネクタを挿す力に対する座屈荷重は最悪で約 8 N (FR-4 は約 300 N)。フィルムだけでは約 0.07 N で座屈するので、支持板なしでは立たない。挿す力そのものは出典が無い |
| 3HP の再確認 | 想定外の干渉なし、光の通り道に A7 の部品なし、ハーネスは D2 から 2.8 mm。D2 の遮光の推定は 2.0 % (FR-4 は 1.9 %)。透明なリーフを通る光は計算に入っていない |
| 電気の確認 (PR #42) | CI で毎回実行。インターフェース (J3 と 2 本の SH4 で左右 2 本のデータ・VLED・GND が両方のチェーンに届く)、機構 (R2 の PET エクスポート)、全パッドが F.Cu の SMD、2 層フィルムでの配線幅・クリアランス・ビア・銅箔から端 0.3 mm は **PASS**。**1 層フィルムでは A5 の銅箔を通せない** (データ 5 ネットが B.Cu とビア 11 個を使う、Q11d)、**カバーレイのブリッジが 0.2 mm で JLC の最小 0.5 mm に足りない** (隣のパッドが 1 つの開口を共有する、Q11f) は **NOT_MET**。2 層の透明 PET でめっきビアが使えるかは JLC の資料に無い (Q11e)。2 層なら積層 1.48 mm でキャップの溝の隙間は片側 約 0.06 mm (R2 の再確認が必要) |
| 電圧降下 (上限値) | TPS2552 の短絡電流制限の最悪値 0.435 A を全区間に直列に流した上限で、VLED と GND の合計が銅厚 12 µm で約 335 mV、18 µm で約 224 mV、35 µm で約 115 mV。実際の消費電流でもレイアウトの結果でもない |
| 結論 | **FR-4 を標準・予備のまま**。PET は機構上は透明な支持板に貼る場合だけ成立するが、電気の確認で Q11d (1 層の銅箔) と Q11f (カバーレイのブリッジ) が未達で、Q11e (2 層のめっきビア) は不明。進めるなら、これらと JLC の回答 (Q11)、SH の挿抜力と点灯時の見え方の実物試験 (#10) がそろってから |
| 新しい未解決事項 | 抜く力 (Q11b)、支持板の貼り合わせの供給元 (Q11a)、2HP での PET (Q11c)、1 層の銅箔 (Q11d)、2 層のめっきビア (Q11e)、カバーレイのブリッジ (Q11f)。Q11d〜Q11f は **PET 案だけを止める** もので、FR-4 のリーフには影響しない。下の未解決事項の表を参照 |
