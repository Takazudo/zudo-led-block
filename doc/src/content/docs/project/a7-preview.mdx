**0.8 mm rigid FR-4への設計変更を [#87](https://github.com/Takazudo/zudo-led-block/issues/87) で進めています。** 透明PET/FPCは現行候補から撤回しました。2HPを優先評価し、成立根拠を確保できなければ0.8 mmの3HPへ進みます。旧モデル・注文承認を新設計の検証済み表示として扱いません。

## 前面から奥へ、4 枚の基板を読む

| 部分 | 役割と位置 |
|---|---|
| PMMA 前面 | 幅 14.9 mm、高さ 128.5 mm、厚さ 2 mm。文字と CV IN / THRU のジャック開口 |
| 制御基板とジャック | 前面に垂直な基板。2 個の PJ-324M ジャックが前面を通る。HX MSK13C02 / C5149819 の設定スイッチは基板側面、取り付け前に操作 |
| LED リーフ 2 枚 | 後方の左右に置く FR-4 基板。左右各 4 画素、別々のデータ列 |
| 拡散板 | LED リーフの外側の半透明 PETG 側板。光学的な見え方は実測していない |
| 電源アダプタと配線 | 上側の電源変換基板から制御基板へ電源を送る。SH4 ハーネスと左右のリーフ間配線もモデルに含む |
| 支持部と締結部品 | スパイン、上下キャップ、ねじ・ナットで構成を保持。造形の適合と荷重は実機確認待ち |

奥行き **30 mm は PMMA 裏面からの設計目標**です。ケーブル・参照ソケットなどを含むモデルの外接寸法を、検証済みの装着寸法とは呼びません。

## 操作と比較

ドラッグで回転、右ドラッグで移動、ホイールで拡大縮小できます。タッチでは 1 本指で回転、2 本指で移動・拡大。表示領域をフォーカスすると矢印で回転、Shift と矢印で移動、プラス・マイナスで拡大縮小できます。部品一覧でも名前と役割を確認できます。

正面は PMMA 側、背面はラック内部側です。「表示部品に合わせる」は現在表示している形状に合わせます。「分解して見る」の間隔は構造を読むためだけのもので、実際の分解・組立手順ではありません。「全体をリセット」で元の組立位置へ戻ります。

新しい通常表示は選定したFR-4案を既定とし、PETを候補選択から外します。2HP比較を残す場合は採用済み・未採用・未確認を区別します。モデル更新と最終hashの確認が済むまでは、旧3HP表示を新0.8 mm設計の証跡に使えません。

## 出典と限界

旧プレビューは `engineering/a7/mechanical/exports/` のGLBに基づきます。変更前に確認したソースは `0c19fea8afe356fc993570e969742e774b7a9914`。寸法と座標は `mechanical/layout.json`、`design-inputs.json`、`front_panel/geometry.json`、部品名と形状区分は各 `verification.json` に基づきます。[プレビューの manifest](/a7-preview/manifest.json) にファイル単位の SHA-256、座標変換、部品対応を記録しています。

部品の簡略形状、クリアランスの包絡、配線シナリオが含まれます。旧表示の緑色PCBは基板envelopeで、銅箔・maskの実形状ではありません。新表示では基材のくすんだ半透明性と、不透明な全層銅箔・部品・残すmaskを区別する必要があります。基材の色・透過・拡散は未測定の見え方の仮定であり、LEDの明るさ・光学性能・熱の試験結果ではありません。表示の分解・非表示は元の工学モデルや承認の識別を変えません。

[A7 の現状](/docs/project/a7/) と [次の作業](/docs/project/next-actions/) に、新設計のデジタル作業と残る実機確認を分けて記録しています。A5 は不変の履歴資料、A6 は保留のままです。
