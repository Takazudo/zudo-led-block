Zudo LED Block は、Kumiko のブランクパネルの横に置く細い Eurorack 用の「光るブロック」です。
透明アクリルの前面に彫った文字が光り、左右の半透明 PETG 側板から隣の Kumiko へ光を当てます。
このリポジトリは、エンジニアリング・チェックポイント **Light Block A5** (2026-11-06 JST) をそのまま取り込み、
その内容をこのサイトで説明しています。

**現在の状態: A5 の設計と部品表 (BOM) を取り込み済み。部品証跡カタログ (component-evidence catalog) への移行は未着手です。**
30 型番・81 点の部品表は [部品表 (A5 BOM)](/docs/architecture/bom/) にすべて掲載しています。
フレームワークの [Components](/docs/components/) セクションは、検証済みの部品証跡バンドルだけから生成されるため、移行が終わるまで 0 件のままです。
これは「部品が無い」という意味ではありません。

## 設計条件 (A5 で維持するもの)

| 項目 | 内容 |
|---|---|
| 幅 | **2HP を優先** (前面 9.8 mm)、3HP (14.9 mm) を同じ電子回路で代替 |
| 前面 | 透明キャスト PMMA、高さ 128.5 mm、厚さ 2 mm |
| 前面の加工 | 見える裏面は全面フロスト、文字線とモード記号だけ透明。O / P / D の内側もフロスト。正面は平滑。締結部の小さな座面だけ透明。裏面彫刻データは **鏡像化済み** |
| 側面の光 | 交換できる半透明 PETG 側板。左右 4 個ずつ、計 8 個の個別制御 RGB LED。左右は独立した 2 本のデータ列 |
| 操作 | ON / PROGRAM / CV の保持型スイッチ。**中央の物理 OFF 接点は PROGRAM** を意味し、電源 OFF ではない |
| CV | IN→OUT は受動 THRU (回路図で指定、制御基板の物理配線は未完)。公称 ±5 V を 20 MΩ の検出枝で読む |
| 奥行き | アクリル裏面 z=0 から、相手コネクタ・ピン・ケーブルの曲げを含めて 30 mm を目標 |
| 組立 | 工場実装と完成ケーブルを使い、差込み・ねじ組立で完成させる構成を目標 (工場対応条件は未確定) |
| 試作方針 | 光学だけの PCB を先行発注しない。レイアウト・適合・リリースの各ゲートを通ってから統合試作 |
| 数量 | 未合意。1 / 10 / 100 台は費用比較の条件 |

## 構成の要点

- **4 枚の物理基板 / 3 種類のネイティブ設計**: 制御基板 (59 点)、同一設計の LED 基板 ×2 (各 10 点)、電源変換基板 (2 点)。合計 **30 型番・81 点 / 台**。
  ユニーク配置数 71 は設計上の数え方で、実装点数 81 とは異なります。
- MCU は STM32G031G8U6TR。ファームウェアは A5 の CV 回路専用で、旧 A4.1 の回路には使えません。
- 詳しくは [システム構成](/docs/architecture/overview/)、[電子回路とインターフェース](/docs/architecture/electronics/)、[機構](/docs/architecture/mechanical/)、[ファームウェア](/docs/architecture/firmware/)、[前面アートワーク](/docs/architecture/front-panel/) を参照してください。
