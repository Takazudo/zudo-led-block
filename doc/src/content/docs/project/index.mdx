Zudo LED Block は、Kumiko のブランクパネルの横に置く細い Eurorack 用の「光るブロック」です。
透明アクリルの前面に彫った文字が光り、左右の半透明 PETG 側板から隣の Kumiko へ光を当てます。
このリポジトリは、エンジニアリング・チェックポイント **Light Block A5** (2026-11-06 JST) をそのまま取り込み、
その内容をこのサイトで説明しています。
現在は、その A5 を基準にした構造変更 **A7** を進めています ([A7 の現状](/docs/project/a7/))。

**履歴資料の状態: A5 の設計と部品表 (BOM) を取り込み済み。30 型番すべてを部品証跡カタログ (component-evidence catalog) に移行しました。**
30 型番・81 点の部品表は [部品表 (A5 BOM)](/docs/architecture/bom/) にすべて掲載し、各行から [Components](/docs/components/) の記録ページへリンクしています。
カタログに載っていることは「製造に使える」という意味ではありません。各記録には、メーカー一次資料で確認した事実と、未確認のまま残る項目 (`OPEN`・`UNSOURCED`・`NEEDS BENCH`・`SOURCE UNAVAILABLE`) がそのまま表示されます。
照合の方法と限界は [部品証跡カタログの照合](/docs/verification/component-catalog/) を参照してください。

## 設計条件 (A5)

| 項目 | 内容 |
|---|---|
| 幅 | **2HP を優先** (前面 9.8 mm)、3HP (14.9 mm) を同じ電子回路で代替 |
| 前面 | 透明キャスト PMMA、高さ 128.5 mm、厚さ 2 mm |
| 前面の加工 | 見える裏面は全面フロスト、文字線とモード記号だけ透明。O / P / D の内側もフロスト。正面は平滑。締結部の小さな座面だけ透明。裏面彫刻データは **鏡像化済み** |
| 側面の光 | 交換できる半透明 PETG 側板。左右 4 個ずつ、計 8 個の個別制御 RGB LED。左右は独立した 2 本のデータ列 |
| 操作 | ON / PROGRAM / CV の保持型スイッチ。**中央の物理 OFF 接点は PROGRAM** を意味し、電源 OFF ではない |
| CV | IN→OUT は受動 THRU (回路図で指定、制御基板の物理配線は未完)。公称 ±5 V を 20 MΩ の検出枝で読む |
| 奥行き | アクリル裏面 z=0 から、相手コネクタ・ピン・ケーブルの曲げを含めて 30 mm を目標 |
| 組立 | 工場実装と完成ケーブルを使い、差込み・ねじ組立で完成させる構成を目標 (工場対応条件は未確定) |
| 試作方針 | 光学だけの PCB を先行発注しない。レイアウト・適合・リリースの各ゲートを通ってから統合試作 |
| 数量 | A5 時点では未合意で、1 / 10 / 100 台は費用比較の条件。A7 の最初の製作は 2 台 (2026-11-12 オーナー決定。[発注前にオーナーが行うこと](/docs/project/order-checklist/)) |

## A7 で変えるもの

A7 ([#15](https://github.com/Takazudo/zudo-led-block/issues/15)) では次の点を変えます。それ以外の条件 (奥行き 30 mm、左右独立の LED 2 列、受動 THRU、MCU のピン割り当て、電源・起動の動作) は A5 を維持します。

| 項目 | A5 | A7 |
|---|---|---|
| 前面 | 文字と CV ジャック 2 個、モードのトグルと ON / PGM / CV の表示 | 光る文字と CV ジャック 2 個 (IN / THRU) だけ。スイッチの穴と表示を外す |
| モード切替 | 前面の ON–OFF–ON トグル | 基板側の側面スライドスイッチ (取り付け前に設定) |
| ジャック | PJ-3582-B | 直角のねじ付き SOFNG PJ-324M |
| 制御基板 | 幅 8.8 mm、前面と平行 | 前面に垂直。奥行きを配線の場所に使う |
| 幅 | 2HP 優先 / 3HP 代替 | 3HP (14.9 mm) を採用。評価した 2HP 配置は不採用 (#87 / PR #88) |
| LED 基板 | 0.6 mm FR-4 | 0.8 mm rigid FR-4 の 2 層 (PR #88)。透明 PET/FPC は 2026-11-17 にオーナーが撤回 (PR #35/#42 の検討は履歴) |

## 構成の要点

- **4 枚の物理基板 / 3 種類のネイティブ設計**: 制御基板 (59 点)、同一設計の LED 基板 ×2 (各 10 点)、電源変換基板 (2 点)。合計 **30 型番・81 点 / 台**。
  ユニーク配置数 71 は設計上の数え方で、実装点数 81 とは異なります。
- MCU は STM32G031G8U6TR。ファームウェアは A5 の CV 回路専用で、旧 A4.1 の回路には使えません。
- 詳しくは [システム構成](/docs/architecture/overview/)、[電子回路とインターフェース](/docs/architecture/electronics/)、[機構](/docs/architecture/mechanical/)、[ファームウェア](/docs/architecture/firmware/)、[前面アートワーク](/docs/architecture/front-panel/) を参照してください。
