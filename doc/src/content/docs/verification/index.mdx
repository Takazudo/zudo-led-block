:::caution[CI が緑でも承認ではありません]
このリポジトリの CI はファイルの同一性、データの整合、ファームウェアの試験とビルド、サイトのビルドを確認します。
電子回路の承認、製造リリース、実機の適合を意味しません。
:::

## 2 種類の結果

| 種類 | 何か | どこで見るか |
|---|---|---|
| **履歴上の結果** | A5 作成時 (2026-11-06) に記録された KiCad 10.0.8 の ERC / DRC、ネットリスト照合、FW 試験、CAD の確認、XLSX / PDF の監査 | [履歴上の検証記録](./historical-records.mdx)、`engineering/a5/` の各記録 |
| **このリポジトリの CI** | 各 PR と `main` への push で新たに実行する確認 | GitHub Actions の `CI` ワークフロー |

CI は KiCad・CadQuery を **再実行しません**。ネイティブ回路・CAD の再生成は別の作業として追跡しています。CI は履歴記録の入力ファイルの SHA-256 を確認し、制御基板が未配線のままであることを表示し続けます。

## CI が実行する確認

| ジョブ | 内容 |
|---|---|
| A5 data | 786 ファイルの同一性 (`scripts/verify_seed.py`)、`build_procurement_rows.py --check`、BOM の照合 (30 型番 / 81 点 = 59 + 10 × 2 + 2)、ネットリスト照合の再実行 (一時出力) と履歴記録との一致、ERC / DRC 記録の入力同一性、FW ソースマニフェスト、生成ページの差分確認、部品証跡カタログの照合 (`scripts/a5_catalog.py reconcile --check` と変異試験) |
| Firmware (host) | `make test`、`make test-sanitize` (ASan / UBSan / LeakSanitizer)、`make timing` をホスト C コンパイラで実行 |
| Firmware (ARM) | Ubuntu 24.04 の署名付きパッケージ `gcc-arm-none-eabi=15:13.2.rel1-2` (A5 の記録と同じコンパイラ) と `binutils-arm-none-eabi=2.42-1ubuntu1+23` で `make arm`。`tools/make_release.py` は **一時コピーの中だけ** で実行し、未解決シンボル・割込みベクタ・容量を確認。新しい HEX / BIN が `dist/` の記録と一致するか比較し、最後に 786 ファイルを再確認 |
| Docs | `circuit:doctor`、`circuit:check`、カタログ整合 (`scripts/a5_catalog.py check`)、`circuit:generate` と差分確認、`pnpm check` (型検査)、`pnpm build`、`pnpm check:site` (公開範囲・リンク・25 MiB / ファイル数の上限)、ブラウザ確認 (デスクトップ / モバイル)、フレームワークの `check-browser` (明示した代表ページ)、Cloudflare Build Output と認証情報なしの dry run |

`scripts/browser-check.mjs` が主要ページ・ナビゲーション・検索・テーマ・画像・ダウンロード・canonical URL・404 に加え、部品証跡カタログ (全 30 記録ページ、資料の選択・例外、ページ内リンク、BOM との対応) をデスクトップで確認します。モバイルではカタログの一覧と代表の記録ページ 2 件を確認します。

フレームワークの `check-browser` は `circuit.config.ts` の `browserSmoke.representatives` で明示した記録ページを、4 つの画面幅 × ライト / ダークで巡回します。ただし CAD が無効でフットプリントが公開されないため、部品参照セクションの検査・3D ビューアの検査は **実行されません (SKIP / NOT RUN)**。これは合格ではなく、未実施の項目です。詳細は [部品証跡カタログの照合](./component-catalog.mdx) を参照してください。

## ローカルでの再現

リポジトリのルートから実行します。

```sh
# A5 のデータ (Python 3.11 以上、標準ライブラリのみ)
python3 scripts/verify_seed.py --manifest provenance/seed-manifest.json --repo .
python3 engineering/a5/build_procurement_rows.py --check
python3 engineering/a5/integration/check_schematic_interfaces.py \
  engineering/a5/integration/native_schematic/controller/netlist.xml \
  engineering/a5/integration/native_schematic/led_leaf/netlist.xml \
  engineering/a5/integration/native_schematic/power_adapter/netlist.xml \
  --output /tmp/a5-interface-check.json
python3 scripts/check_a5_records.py

# ファームウェア (GNU Make + ホスト C11 コンパイラ、ARM は arm-none-eabi-gcc 13.2.1)
make -C engineering/a5/firmware test test-sanitize timing
make -C engineering/a5/firmware arm

# ドキュメント (Node 24、pnpm 11.5.2)
pnpm install --frozen-lockfile
pnpm circuit:doctor && pnpm circuit:check && pnpm build && pnpm check && pnpm check:site
pnpm test:browser
```

`--output` を省略するとネットリスト照合は履歴記録 (`integration/schematic_interface_check.json`) を上書きします。`make_release.py` は `dist/`・ログ・ハッシュ・ライセンス・検証記録を書き換えるので、必ずファームウェアのコピーで実行してください。
