A5 チェックポイントの設計内容を分野ごとに説明します。数値の出典はすべて `engineering/a5/` の記録で、このサイトは要約と案内だけを行います。

- [システム構成](./overview.mdx) — 4 枚の基板、2 本の LED データ列、電源の流れ
- [部品表 (A5 BOM)](./bom.mdx) — 30 型番・81 点、基板別の数量と日付付きの費用比較 (自動生成)
- [電子回路とインターフェース](./electronics.mdx) — コネクタのピン配置、ケーブル、CV 入力、基板の状態
- [機構 (2HP / 3HP)](./mechanical.mdx) — 背面 CAD、印刷部品、不採用のケーブル経路
- [ファームウェア](./firmware.mdx) — モード、LED タイミング、故障時の動作と限界
- [前面アートワーク](./front-panel.mdx) — A4 意匠の維持、彫刻と加工の意図

部品ごとの証跡 (データシートの事実・ピンマップ・検証) は [Components](/docs/components/) の部品証跡カタログにあります。

これらのページは A5 の設計を説明しています。A7 構造変更 (直角ジャック・垂直な制御基板・基板側の設定スイッチ) の状態は [A7 の現状](/docs/project/a7/) を参照してください。A7 の回路図 (`engineering/a7/electronics/`) と暫定の機構モデル (`engineering/a7/mechanical/`、`front_panel/`) は `main` にありますが、基板がまだ無いため、これらのページには反映していません。
