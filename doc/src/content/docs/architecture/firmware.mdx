## 対象

- MCU: **STM32G031G8U6TR** (UFQFPN28、Cortex-M0+、Flash 64 KiB、SRAM 8 KiB)
- 対象回路: **A5 の U7 フォロワーと R24 = 330 Ω / R25 = 1 kΩ**。**A4.1 の回路に書き込まないでください。**
- コンパイラ (記録): `arm-none-eabi-gcc (15:13.2.rel1-2) 13.2.1 20231009`
- 容量 (記録): Flash 10,712 / 65,536 B、静的 RAM + 予約スタック 3,848 / 8,192 B

## モード (試作の初期値)

| モード | 動作 |
|---|---|
| ON | 8 画素すべて白。各色コード 51 (255 の 20 %) が上限 |
| PROGRAM (中央の物理 OFF 接点) | 8 秒周期の三角波の呼吸。左は暖色、右は寒色、半周期ずらす |
| CV | CV の絶対値で明るさ、正で暖色・負で寒色。±50 mV の不感帯、±5 V で最大、それ以上は飽和 |

スイッチのビット (PA2, PA3): `01` ON、`11` PROGRAM、`10` CV、`00` 無効 (消灯)。変化は 20 ms の安定で確定します。
20 % の上限は PWM の指令値の上限で、光量・電流・温度の保証ではありません。

## LED タイミング

60 MHz、TIM3 の 1 セル 78 tick、0 / 1 の High は 21 / 57 tick。左右を並列に出力します。
リセット期間は +3 % のクロック上限でも 320 µs 以上 (要求 280 µs 以上)。対象の LED は固定した Worldsemi WS2812B-2020-V6 のデータシートです。
これはソフトウェア上の計算で、オシロスコープでの測定ではありません。

## 故障と復帰

- FAULT、古い / 不正な ADC、DMA の異常で LED 電源を切り、データ線を Low にします。自動の再試行はありません。
- 起動中・有効化済み・故障の記録をバックアップレジスタに保持し、危険なウォームリセット後は消灯を維持します。通常の完全な電源断の後は、特別な操作なしで起動します。
- **限界**: バックアップ電源まで失われる故障では記録が消え、再起動で再試行し得ます。独立した 5 V 正常監視はなく、FAULT 前の 5 V だけの低下・復帰はウォームリセットの保証範囲外です。LDO の逆電流と 5 V だけの低下はベンチで確認するゲートとして残っています。
