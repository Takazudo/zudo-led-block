:::caution[制御基板は未配線]
制御基板には銅配線もプレーンもありません。記録上、未接続 130 項目とコートヤードの重なり 2 件 (J3-H1、J3-C7) が残っています。
回路図 (ERC) の結果がきれいでも、配線が終わっていることにはなりません。
:::

ネイティブの編集元は `engineering/a5/electronics/native/` の 3 つの KiCad 10 プロジェクト (`controller`、`led_leaf`、`power_adapter`) です。
フットプリントは自己完結した `LightBlock.pretty` ライブラリと、ライセンス付きの上流オリジナル (`electronics/footprints/upstream/`) を同梱しています。

## LED ハーネス (2 本の独立したデータ列)

制御基板の LED 用コネクタは **J3 だけ** です (A5 で J4 を削除)。既製の 1:1 の SH4 ケーブルを 2 本使います。

| 物理ケーブル | ピン 1 | ピン 2 | ピン 3 | ピン 4 |
|---|---|---|---|---|
| 制御 J3 → 左 LED 基板 J1 | GND | VLED | 左 DATA | 右 DATA |
| 左 LED 基板 J2 → 右 LED 基板 J1 | GND | VLED | 右 DATA | 左 DATA (右基板では未使用) |

- 各 LED 基板の J1 はピン 3 / 4 = THIS / OTHER、J2 はピン 3 / 4 = OTHER / THIS です。入替えは基板の銅箔で行うので、ケーブルは 1:1 のままです。
- 右 LED 基板の J2 は外部に接続しません (VLED・GND・データが出ているので絶縁を維持)。
- これはプロジェクト独自のピン割当てで、**Qwiic の信号割当てではありません**。
- 最初のケーブルが両方の LED 基板の電流を運びます。
- 右の LED 基板は上下反転して実装するので、縦位置でそろえるパターンでは右側の画素番号を逆順にする必要があります (現在の初期値は左右それぞれ一色なので影響なし)。

## 電源ハーネス

Molex 151340300 の完成ケーブルは **ピン 1 と 3 が反転** します。

| 場所 | ピン 1 | ピン 2 | ピン 3 |
|---|---|---|---|
| 制御基板 J5 | +12 V | GND | −12 V |
| 電源変換基板 J2 | −12 V | GND | +12 V |

電源変換基板の IDC10 は ピン 1/2 = −12 V、3〜8 = GND、9/10 = +12 V です。実物のケーブルの向きと極性表示で確認してください (線の色だけで判断しない)。

## MCU のピン

| MCU ピン | 信号 | 用途 |
|---:|---|---|
| 6 | PA0 | A5 で分圧した CV (ADC ch0) |
| 8 / 9 | PA2 / PA3 | MODE_A / MODE_B (外部 10 kΩ プルアップ) |
| 10 | PA4 | TPS2552-1 の FAULT (アクティブ Low) |
| 11 | PA5 | High で LED 電源有効 (NPN 経由で /EN) |
| 12 / 13 | PA6 / PA7 | TIM3_CH1 / CH2、左 / 右の LED データ |
| 20 / 21 / 5 | PA13 / PA14 / NRST | SWD サービスパッド |

## CV 入力 (A5)

A5 では OPA197 の後段に **U7 TLV9001** を追加し、**R24 = 330 Ω / R25 = 1 kΩ** で ADC 電圧を分圧します。**C13 は R7 の上流** (CV_AFFINE) に移し、コンデンサの放電が U7 入力に届く経路にも R7 が入るようにしました。

```text
Vnode = VDD / 2 + CV / 8
VADC  = (100 / 133) × Vnode
CV    = 10.64 × VADC − 4 × VDD
```

VDD = 3.3 V、CV = −5 / 0 / +5 V で ADC は約 0.771 / 1.241 / 1.711 V です。抵抗公差・基準電圧・オフセットは校正の対象で、**測定による校正の手順や結果はまだありません**。
**A5 のファームウェアは旧 A4.1 の ADC 回路とは互換性がありません。**

条件付きの DC 電流計算は記録されていますが、任意の電源過渡を保証するものではありません。部分電源、急な電源断、LDO の逆電流、5 V だけの低下は実機で確認する必要があります。

## 記録された回路・基板の確認

- 3 回路の ERC (KiCad 10.0.8): 0 エラー / 0 警告 (既定の除外カテゴリは記録に残してあります)。
- XML ネットリストに対する独立したピン・配線・数量の照合: 42 項目 PASS。
- LED 基板・電源変換基板の DRC: 違反 0、未接続 0。

これらは **A5 作成時の履歴上の結果** です。このリポジトリの CI は KiCad を再実行せず、ネットリスト照合を再実行し、記録と入力ファイルの SHA-256 を確認します。詳しくは [履歴上の検証記録](/docs/verification/historical-records/) を参照してください。
