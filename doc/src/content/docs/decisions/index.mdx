A5 で有効な判断をまとめます。過去版の資料 (`engineering/a5/history_A4/`、`history_A4_1/`、前面の `reference_A3/`) は履歴として残しています。
旧価格・旧 ADC 式・当時の実装状況は A5 の値を上書きしません。古い調査 (`research_jlc_electronics`、`io_service_audit`、`harness_supply_followup`) も日付付きの調査記録です。

## 主な判断

| 判断 | 内容 | 理由 |
|---|---|---|
| 幅 | 2HP を優先、3HP を同じ電子回路で代替 | Kumiko の横に置く細いモジュールにしたい。2HP で収まらない場合の逃げ道を残す |
| 前面 | A4 の全面フロスト・透明文字の意匠を維持 | 独立監査済みの 29 ファイルを変更しない |
| LED 配線 | 制御 J3 の 1 本の SH4 で左右 2 本のデータを送り、左 LED 基板で入替えて右へ渡す。J4 を削除 | 制御 J4 とスイッチ端子の干渉を解消し、2 本の既製 1:1 ケーブルで独立した 2 列を保つ |
| CV 入力 | U7 TLV9001 と R24 / R25 の分圧を追加。C13 を R7 の上流へ | ADC 入力のバッファと、電源断時に C13 の電荷が U7 へ流れる経路の制限 |
| ファームウェア | A5 の ADC 式専用。A4.1 とは非互換 | アナログ回路の変更に合わせて変換式を変更 |
| 故障時 | 自動再試行なし。保持記録があれば消灯を維持 | TPS2552-1 のラッチが EN で解除され得るため、FAULT の解除を再有効化の許可とみなさない |
| 試作 | 光学専用 PCB を先行発注しない。統合試作で評価 | 回路・機構・FW がそろった状態でしか意味のある評価にならない |
| 数量 | 未合意。1 / 10 / 100 台は比較条件 | 発注判断の前に見積りが必要 |
| 調達の観測 | 2026-11-06 JST の価格・在庫を日付付きで保持 | 在庫予約ではなく、比較のための観測値 |

## 版の流れ

| 版 | 位置づけ |
|---|---|
| A3 | 初期の前面と穴位置 (`front_panel/reference_A3/`、比較用) |
| A4 | 現在も使う前面意匠 (全面フロスト + 透明文字) |
| A4.1 | 回路・調達の前版。247 アーカイブ項目を復元照合。旧 ADC 回路 |
