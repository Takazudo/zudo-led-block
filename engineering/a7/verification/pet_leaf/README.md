# A7 PET LED リーフ（貼り合わせ型）の電気プロファイルとインターフェースチェック（R4 項目 5, #19）

**状態: プロファイルとチェックだけです。リーフの設計ではありません。PET の採用も承認していません。** FR-4 の A5 リーフが既定で、代替案でもあります。製造用のリリースもしていません。

対象は R2 が PR #35 で比較した貼り合わせ型です（`engineering/a7/mechanical/layout.md` の「LED leaf: FR-4 (default) versus clear PET FPC on a clear carrier」）。透明 PET フィルムを OCA で厚さ 0.8 mm の透明 PC キャリアに貼り、フィルムは両面に 1 枚ずつです。フィルム単体では SH の嵌合力で座屈するため、単体のリーフは対象外です。

## ファイル

- `profile.json` — プロファイル（authored）です。次の内容を記録しています。
  - 積層と 1 層・2 層の 2 案
  - JLC のフレキ基板の設計ルール（URL、取得時刻、sha256、該当行の抜粋つき）
  - 電流の上限
  - インターフェースの要件
  - 現在の判定の期待値と、未解決の質問
- `scripts/a7_pet_leaf_check.py` — チェックです。`--out` にはリポジトリ外の空ディレクトリを指定します。CI の native ジョブで毎回実行します。

## チェックの内容

1. **インターフェース**: レビュー済みのロールマップ（`interface_roles/a7_controller.json`）で振る舞いアサーションを実行します。対象はコントローラー J3、2 本の SH4 ハーネス（J3 → 左リーフ J1、左リーフ J2 → 右リーフ J1）、リーフ内の配線です。ネットリストはコミット済みの A7 コントローラーと A5 リーフ・アダプターのものを使います。
2. **機構**: R2 の 3HP PET エクスポート（`mechanical/exports/3hp_pet/verification.json`）が PET リーフを持ち、エンベロープや剛体干渉の指摘がなく、製造リリースが false であることを確かめます。
3. **銅箔**: ピン留めの KiCad イメージで、A5 リーフ基板のコピー（`--out` 内）に対して次を調べます。
   - パッドの種類と層
   - 層ごとの配線とビア
   - フットプリントごとのパッド間隔
   - JLC フレキ基板の「銅箔から基板端まで 0.3 mm」ルールを足したネイティブ DRC。不可能な端距離ルールを入れた対照の DRC も実行し、ルール名つきで検出されなければ失敗にします。
4. **電圧降下の上限**: TPS2552 の最悪の電流制限値（R11 = 68 kΩ で IOSmax 約 0.435 A）で計算します。左リーフは J2 から右リーフにも給電するため、すべての VLED と GND の区間をこの電流で直列に足して上限を出します。

各判定は `PASS` か `NOT_MET` です。`NOT_MET` は PET 案についての指摘で、チェックの失敗ではありません。新しく出した判定が `profile.json` の `expected` と違う場合は、チェックを失敗にします。プロファイル、ルール、元の基板が変わったときに、黙って通らないようにするためです。

**電圧降下は上限値です（レイアウトの結果ではありません）。** VLED と GND の合計で、銅厚 12 µm で約 335 mV、18 µm で約 224 mV、35 µm で約 115 mV です。前提は次のとおりです。

- 電流は TPS2552 の短絡電流制限の最悪値 IOSmax（R11 = 68 kΩ で 0.435 A）です。実際の消費電流ではありません。ファームウェアの code≤51 は PWM の上限で、電流の上限ではないため使っていません。
- A5 リーフの VLED と GND のすべての区間を、この電流で直列に足しています。分岐を重複して数えるので、実際より大きくなります。
- 配線幅は A5 の値を使い、銅の抵抗率は 1.72e-8 Ω·m（20 °C）です。温度上昇と ENIG は含みません。
- コネクタ接点とハーネスの抵抗は含みません。

## 積層の 2 案

- **1 層（0.14 mm）**: R2 がモデル化した案です。積層 1.28 mm で、キャップのスロットの隙間は片側 0.16 mm です。ただし A5 の銅箔パターンは移せません（上の表）。
- **2 層（0.24 mm）**: A5 の銅箔パターンはルール上は通ります。ただし透明 PET でめっきスルーホールが使えるかは、JLC の資料に書かれていません。積層は 1.48 mm で、R2 の数値から推定するとスロットの隙間は片側 0.06 mm です。R2 の再確認が必要です。
