## 段取り料金は部品の種類数で決まり、Basic に替えても減らない

JLC の料金ページ（2026-10-22 更新）では、Standard PCBA は Basic と Extended のどちらも 1 種類 $1.53、Economic PCBA は Extended だけ 1 種類 $3.07 です。コントローラーと LED リーフは両面実装などで Standard、電源アダプタは Economic です（`jlc-package/package.json`）。

| 基板 | 区分 | 種類 | うち Extended | 料金 |

| controller | STANDARD | 28 | 14 | $42.84 |
| led_leaf | STANDARD | 3 | 2 | $4.59 |
| power_adapter | ECONOMIC | 2 | 2 | $6.14 |

コントローラーとリーフでは Extended を Basic に替えても料金は同じで、減らせるのは種類を減らすときだけです。アダプタの 2 種類（Molex 530470310 と 2×5 ヘッダー）はコネクタで、コーディネーターの判断で変えません。セットアップ、ステンシル、はんだ点数、手はんだ、PCB 製造、送料と税は含みません。スルーホール部品が段取り料金に数えられるかは料金ページに書かれていません。
