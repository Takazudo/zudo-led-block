# A7 調達・組立の準備台帳

このディレクトリは **3HP / 1.6 mm コントローラー / FR-4 リーフ** の工程準備用です。発注用 BOM / CPL、製造承認、見積り、在庫予約ではありません。数量は未合意です。

- `assembly-manifest.json`: 基板・入力ファイルの SHA-256、全実装リファレンス、DNP / テストパッド除外、外部部材、治具、サービス、未解決事項。
- `population.csv`: 人による実装点数確認用。**供給元へアップロードしないでください。**
- `ledger.md`: 点数と基板識別の要約。

上記 3 ファイルは `python3 scripts/a7_procurement.py` が生成します。手編集せず、入力を修正して再生成してください。`--check` は現在入力との完全一致を確認し、古い識別、点数、二重計上や省略を拒否します。`python3 -m unittest scripts/tests/test_a7_procurement.py` が負の対照を実行します。

実装方式（SMD/THT）と面は、コントローラーが `fixture/native-geometry.json`（権威基板の SHA に結合した native export）のパッド属性、リーフとアダプタが不変 A5 の配置データのパッド属性から決まります。電源ケーブルと SH4 のピン対応は両端のネットリストから生成し、ネットが合わなければ失敗します。未解決事項は区分付き（`blockers[].class`）で、readiness がそれぞれを別のゲートとして扱います。

コントローラーは現在の A7 ネットリスト、カタログの A7 置換 3 点、実基板に結び付いた native 配置を照合します。リーフと電源変換基板は不変 A5 のネットリストと配置を参照します。リーフだけ 2 枚に掛け、71 配置を 81 実装点へ換算します。A5 の価格や在庫は現在値として転記しません。すべての購入行で現在の価格・在庫・MOQ・包装・納期・実装サービス適用性が揃うまでは調達未確定です。

機構部材はコミット済み 3HP FR-4 機構検証の部品表から生成します。トップキャップのボスと底キャップのフォークは一体形状なので別購入部品に数えません。ねじ・ナット・ワッシャーの形状包絡は注文型番ではありません。ジャック用 M6×0.5 ナットの同梱・適合、PMMA の公差とポケット、PETG、接着層、ラック締結部品は未確定です。電源ケーブルは `mechanical/layout.json` の要求をそのまま参照し、旧 A5 Molex 151340300 を代用品として載せません。

治具の材料は `fixture/materials.json` があれば取り込み、**モジュール 1 台当たりではなく治具 1 台当たり**として分離します。候補と採用品を混同しません。ソケット・ガイド・配線・支持材が未確定なら治具は未完のままです。

台帳の一致確認は native ERC / DRC、実装方向レビュー、現物の適合や電気・温度・光学評価を代替しません。A5 の配置は履歴データであり、新しい測定結果ではありません。書込みファームウェアの SHA は識別だけで、WS2812B-2020-V6 の T1L 問題 (#13) を解決しません。#8 / #10 / #17 / #19 の物理ゲートとオーナー承認が残ります。
