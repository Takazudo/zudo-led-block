# A7 調達・組立の準備台帳

このディレクトリは **3HP / 1.6 mm コントローラー / FR-4 リーフ** の工程準備用です。発注用 BOM / CPL、製造承認、見積り、在庫予約ではありません。最初の発注数量はオーナーが 2 台と決めました（`owner-decisions.json`、オーナーの原文つき）。JLC の PCBA 最小 2 枚はオーナーの報告で、2026-11-12 に JLC の公開能力表（Order Volume 2 - 50 / 2 - 80000 pcs）で確認しました。

- `assembly-manifest.json`: 基板・入力ファイルの SHA-256、全実装リファレンス、DNP / テストパッド除外、外部部材、治具、サービス、未解決事項。
- `population.csv`: 人による実装点数確認用。**供給元へアップロードしないでください。**
- `ledger.md`: 点数と基板識別、部品ごとの日付付き観測の要約。
- `sourcing-projection.json`: 実装する 30 型番それぞれについて、日付付きの JLC 掲載観測（`../jlc-package/sources.json` の部品ページ受領記録と `price-audit/2026-11-12.json` の部品 API 点検）、取得時刻と SHA-256、こちらの解釈（項目の意味・通貨・購入数の計算）と、どの型番も未取得の項目（納期・確定見積・在庫確保・実装受入）。二つの読み取りは別時刻で、同時点のスナップショットではありません。外した PCM13SMTR（C221842）は `retired` に履歴として残します。生成した `jlc-package/package.json` は入力にしません（この台帳を読むため循環になる）。

手で書く入力（生成物ではありません）:

- `owner-decisions.json`: オーナーの判断と原文。発注数量（2 台）と調達の優先順（JLC 在庫 → JLC 予約注文または Global Sourcing → 例外）。推奨ではなく、オーナー自身の回答だけを記録します。部品選定のオーナーの方針（2026-11-12「basicallly choose JLC basic parts or have qty items. it's better」）: 部品を選ぶ・替えるときは、JLC の Basic 部品か、JLC が十分な在庫を持つ部品を優先する（`sourcing_preference.part_selection`）。方針であり、BOM や基板をそれだけで変えるものではありません。
- `supply-observations.json`: 日付付きの供給元掲載の観測（取得時刻・URL・raw の SHA-256・抜粋）。在庫確保・見積・実装受入ではありません。

上記 4 ファイルは `python3 scripts/a7_procurement.py` が生成します。手編集せず、入力を修正して再生成してください。`--check` は現在入力との完全一致を確認し、古い識別、点数、二重計上や省略を拒否します。`python3 -m unittest scripts/tests/test_a7_procurement.py` が負の対照を実行します。

実装方式（SMD/THT）と面は、コントローラーが `fixture/native-geometry.json`（権威基板の SHA に結合した native export）のパッド属性、リーフとアダプタが不変 A5 の配置データのパッド属性から決まります。電源ケーブルと SH4 のピン対応は両端のネットリストから生成し、ネットが合わなければ失敗します。未解決事項は区分付き（`blockers[].class`）で、readiness がそれぞれを別のゲートとして扱います。

コントローラーは現在の A7 ネットリスト、カタログの A7 置換 3 点、実基板に結び付いた native 配置を照合します。リーフと電源変換基板は不変 A5 のネットリストと配置を参照します。リーフだけ 2 枚に掛け、71 配置を 81 実装点へ換算します。A5 の価格や在庫は現在値として転記しません。2026-11-12 の観測は現在の在庫や購入条件の保証ではなく、納期・確定見積・在庫確保・実装受入が揃うまでは調達未確定です。

機構部材はコミット済み 3HP FR-4 機構検証の部品表から生成します。トップキャップのボスと底キャップのフォークは一体形状なので別購入部品に数えません。ねじ・ナット・ワッシャーの形状包絡は注文型番ではありません。ジャック用 M6×0.5 ナットの同梱・適合、PMMA の公差とポケット、PETG、接着層、ラック締結部品は未確定です。電源ケーブルは `mechanical/layout.json` の要求をそのまま参照し、旧 A5 Molex 151340300 を代用品として載せません。

治具の材料は `fixture/materials.json` があれば取り込み、**モジュール 1 台当たりではなく治具 1 台当たり**として分離します。候補と採用品を混同しません。ソケット・ガイド・配線・支持材が未確定なら治具は未完のままです。

台帳の一致確認は native ERC / DRC、実装方向レビュー、現物の適合や電気・温度・光学評価を代替しません。A5 の配置は履歴データであり、新しい測定結果ではありません。書込みファームウェアの SHA は識別だけで、WS2812B-2020-V6 の T1L 問題 (#13) を解決しません。#8 / #10 / #13 の物理ゲートとオーナー承認が残ります。
