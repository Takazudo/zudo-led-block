# engineering/a7/front_panel — A7 front artwork

Clear 2 mm cast PMMA with a full rear frost and clear (unprocessed) lettering. The front stays smooth. This
keeps the A4/A5 finish, font and cap height.

**Removed from A5:** the switch aperture, the MODE label, the ON / PGM / CV legends with their arrow and dot
icons, and the A5 Y65 controller hole. **Kept:** the outline, rack slots and two front M2 screws (Y 20.5 and
60.8), now at the X positions of the A7 spine. **New:** IN and THRU, each above its jack.

Generated by `build_a7_front.py` from `../mechanical/layout.json`, for both widths:

| File | Use |
|---|---|
| `geometry.json` | Derived front description (holes, labels, pockets) |
| `exports/front_A7_<w>_CUT.svg/.dxf`, `front_A7_<w>_2mm.step` | Through-cut profile and the 2 mm panel solid |
| `exports/rear_A7_<w>_REAR_FULL_FROST_CLEAR_LETTERS.svg/.dxf` | Rear frost mask; already mirrored (X_rear = W − X) |
| `exports/rear_A7_<w>_JACK_POCKETS.svg` | 0.5 mm rear jack pockets (R1 option `rear-pocket`) |
| `exports/appearance_A7_{front,rear}_<w>.png` | Appearance previews (not a light simulation) |
| `exports/validation_A7.json` | Mask/through-hole/letter partition, removed-label and pocket checks |

The pocket floors are frosted after pocketing, so the field stays uniform. Whether the pocket walls still
read through the clear front, plus the pocket depth tolerance and strength, is open (R1 Q8). No engraving
depth, laser settings or kerf compensation is assigned. This is not an order file.
