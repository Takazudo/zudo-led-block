Every evidence set the A7 work relies on, sorted by what kind of evidence it is. The four classes are kept
apart on purpose: an A5 historical record is not an A7 result, held A6 work is not A7 progress, and no
digital result stands in for physical qualification.

Last synchronised with `main` at `f4c0627` plus the sourcing and documentation reconciliation (#80, #20), 2026-11-13 UTC.
Every A7 engineering PR named here is merged; the current pre-order state is summarised at the top of
[`continue-here.md`](continue-here.md). Check the open PRs before starting new work.
