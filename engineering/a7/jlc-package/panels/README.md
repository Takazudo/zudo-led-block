# リポジトリ面付け（準備済みの経路・未リリース）

**アップロード・発注しないでください。** readiness の発注ゲートは BLOCKED で、面付けの経路（リポジトリ面付けか Panel by JLCPCB か）はオーナーの判断 `assembly:panel-route` で未決です。ここにあるのは、リポジトリ面付けを選んだ場合に必要なものを先に作って確かめた準備です。

- `<board>-panel.json`（生成）: シート寸法、各基板の位置（凍結ファイルからの移動量）、切り溝、マウスバイトタブと穴、フィデューシャル、治具穴、DRC の例外。
- `<board>-panel_BOM_DRYRUN.csv` / `<board>-panel_CPL_DRYRUN.csv`（生成）: 単品の BOM / CPL を基板ごとに移動したもの。2 枚目以降の designator は `_2` などの接尾辞。CPL の原点はシートの左上の外形角（mm、Y は下向きが負）。
- `build-receipt.json`: 最後に全検査が通ったビルドのファイル名一覧。

| 基板 | シート | 載せる枚数 |
|---|---|---:|
| controller | 70 × 76.9 mm | 1 |
| led_leaf | 70 × 96.5 mm（捨て部分は FR-4 のまま） | 2 |
| power_adapter | 22.8 × 44 mm | 1 |

`python3 scripts/a7_panel.py` が生成し、`--check` が一致を確かめます。`python3 scripts/a7_panel.py build --out <リポジトリ外の空ディレクトリ>` はピン留めの KiCad 10.0.8 イメージ（ネットワークなし、リポジトリは読み取り専用）で面付け基板を作り、次を確かめてから Gerber・drill の zip を出します。

- 各基板のパッド・配線・ビア・ゾーン・図形が、凍結した基板ファイルと（移動量を除いて）一致する。
- 各基板の外形が凍結ファイルの外形と一致する（差の面積 0）。
- 穴は「凍結ファイルの穴を移動したもの＋マウスバイト穴＋治具穴」と一致する。
- 面付け DRC が、元の基板の DRC にない違反を足さない（記録した例外を除く）。
- CPL が KiCad 自身の位置出力と一致する（位置・回転・面）。

規則は `../sources.json` の JLC のページ（2026-11-12）から: 5 mm のレール、2 mm の治具穴、1 mm のフィデューシャル（縁から 3.85 mm）、基板間隔 2 mm 以上、タブ幅 5 mm 以上、マウスバイト穴 0.5–0.8 mm・間隔 0.2–0.3 mm。フィデューシャルのマスク開口 2 mm、治具穴の位置、タブと部品の距離 1 mm、はみ出す部品への 1 mm の逃げは提案値で、JLC の値ではありません。凍結した基板ファイルは書きません。
