# Light Block A4.1

更新日: 2026-11-06 JST

中断したA4ソースを復元し、前面加工データの独立検証、JLC在庫・価格の更新、インダクタの低価格品への再選定を行いました。主BOMは **29型番・76点/台**。前面の形状・意匠はA4から変更していません。

**この版は前面加工データと部品選定の成果物です。** 完成機構、KiCad実配線、ERC/DRC、製造BOM/CPL、動作FW、ケーブルを含む30 mmの収まりは未完成です。前面単体のSTEPをモジュール全体の製造リリースと扱わないでください。

## 継続する仕様

- 2HP第一候補、3HP代替。高さ128.5 mm、幅9.8 / 14.9 mm、前面厚2 mm。
- パネル裏から30 mmを目標に、相手コネクタとケーブルの曲げまで含める。
- 交換できる半透明PETG側板。隣のKumikoの層間へ横から光を入れる。
- ON / PROGRAM / CVの3モード。INとOUTは受動THRU直結、CV検出は別枝。
- 左右4個、合計8個の個別制御RGB LED。片面実装の同一0.6 mm FR-4板2枚を背中合わせにする。
- 基板はJLCで実装し、自宅でははんだ付けしない。工場の手はんだは許容。完成ケーブルを別手配して差し込む。
- 光学専用PCBの先行発注はしない。完成した統合試作機でPETG厚さ・造形条件・光・温度を評価する。

## 透明文字と全面フロスト

透明キャストPMMAの裏面を、文字線以外フロスト彫刻します。Oなどの文字内部もフロスト、文字線は透明です。正面は平滑な原面のままです。ElecrowにはTransparent (000)、2 mmを希望し、材種と仕上げは個別見積りで確認します。最初からマットな板では透明な文字を作れません。[1,2]

「全面」は正面から見える面を指します。締結部品の下に隠れる小さな座面、合計約47.66 mm²/板だけは透明のままです。広い透明な外縁やジャック周囲の透明な輪は設けません。

## インダクタの低価格化

A4のWürth74437324047を **TDK SPM4020T-4R7M-LR / C694586** へ変更しました。メーカー現行品、4.7 µH±20%、最大高さ2.0 mm、最大外形4.6×4.3×2.0 mmです。LRの付かない旧品は廃止品なので採用しません。[6]

10台比較の単価は$1.5831から$0.3802となり、**$1.2029/台**を削減します。新しい基板へ採用する選定であり、既存ランドへの無条件な差替えではありません。Würthは `alternative_components` にフォールバックとして保持し、主BOMの費用には含めません。

公称12 V→5 V、1.1 MHz、4.7 µH、出力0.4 Aでは、計算上リップル0.564 App、ピーク0.682 A、実効値0.432 Aです。正常負荷の余裕はあります。ただし飽和電流は典型値であり、高温保証最小値ではありません。正確なパッド、起動、上流短絡と高温での動作は今後検証します。下流LEDラッチだけでは、その上流の短絡を保護できません。

## 機構と回路に残る確認

無ねじPJ-3582-Bの挿入・抜去荷重、トグル回り止め、座面、工場での長い端子のトリムを含むPETG支持体が必要です。SH4は相手ハウジングを含めると中央の光学空間へそのまま収まらず、下端で位置をずらすなどの逃げが必要です。電源変換基板とケーブルも含めて全体を設計します。**A3の29.5 mmをA4.1全体の奥行き保証には使いません。**

CVは公称20 MΩ検出枝、THRU直結、`VADC = V3V3/2 + CV/8`。抵抗のみの最悪組合せは±5 Vで最大約0.233 Vの入力換算誤差です。FWでゼロ/ゲインを校正します。ADC負側保護、電源OFF時注入、逆接、MLCC実効容量、降圧ループは未完の設計確認です。

TPS2552DBVR-1はEN切替でラッチ解除します。MCUリセット後に毎回自動でLEDを再有効化すると故障後も再試行するため、FAULT、リセット理由、故障記録、明示的復帰条件をFWで定義する必要があります。20%の初期輝度制限と過電流遮断は別機能です。
