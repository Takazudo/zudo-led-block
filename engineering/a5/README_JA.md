# Light Block A5

更新日: 2026-11-06 JST

A4.1から、編集できるKiCad回路・基板、STM32で実際にビルドしたファームウェア、背面の機構設計へ進めた版です。前面の意匠はA4を維持しています。主BOMは **30型番・81点/台** です。

**開発チェックポイントであり、製造リリースではありません。** 制御基板の未配線、全ケーブルを含む外形、電源過渡と温度、実物の光と機械強度が残っています。実行した確認とその範囲は verification_A5.json、各分野の記録、技術更新PDFを参照してください。

## 継続する設計条件

- 2HP優先、3HP代替。高さ128.5 mm、幅9.8 / 14.9 mm、前面は2 mm透明キャストPMMA。
- アクリル裏面をz=0として、相手コネクタと配線の曲げまで含む後方30 mmを目標とする。
- 見える裏面を全面フロスト、文字線とモード記号を透明に残す。O/P/Dの内側もフロスト。正面は平滑。
- 交換できる半透明PETG側板から、隣のKumikoへ横方向に照射する。
- 左右4個ずつ、合計8個の個別制御RGB LED。左右で独立したデータ列。
- ON / PROGRAM / CV。中央の物理OFF接点をPROGRAMに使うため、中央は電源OFFではない。
- IN→OUTは受動THRU直結。公称±5 Vを20 MΩの検出枝で読む。
- 工場実装と完成ケーブルを使い、家庭では差込み・ねじ組立で完成できる構成を目指す。工場対応条件は未確定。
- 光学専用PCBを先行発注せず、完成した回路・機構・FWによる統合試作で評価する。
- 1/10/100台は費用の比較条件。ユーザーが確定した発注数量ではない。

## 回路とFWの境界

制御J3の4線をGND / VLED / 左DATA / 右DATAとして使います。左LED板のJ1で受け、J2でデータ線の役割を入れ替えて右LED板のJ1へ渡します。既製1:1ケーブル2本で左右独立の4画素列を維持し、スイッチ端子と干渉する制御J4を取り除きました。右板のJ2は未使用です。各LED板は同一設計・同一実装です。

A5ではOPA197の後段にTLV9001IDBVRを置き、R24=330 Ω / R25=1 kΩでADC電圧を分圧します。C13はR7の前のCV_AFFINEへ置き、コンデンサの放電がU7入力へ達する経路にもR7を入れます。

    Vnode = VDD / 2 + CV / 8
    VADC = (100/133) × Vnode
    CV = 10.64 × VADC − 4 × VDD

VDD=3.3 V、CV=-5/0/+5 VではADC約0.771/1.241/1.711 Vです。抵抗公差、基準電圧、オフセットは校正対象です。**A5バイナリは旧A4.1のADC回路にそのまま使えません。** 条件付きDC電流計算と、任意の電源過渡を保証することは別です。実機の立上り・立下り、部分電源、LDO逆電流を確認する必要があります。

FWは60 MHz、TIM3の78 tick/cell、0/1のHigh=21/57 tickで左右を並列制御します。7スイート・987,189アサーション、ASan/UBSan、±3%クロックの60,001点確認、ARMコンパイル/リンク、割込みベクタ検査を通過しました。書込み・実測はしていません。Flashは10,712 B、静的RAMと予約スタックは合計3,848 Bです。

ONは白、PROGRAMは左右逆位相の8秒呼吸、CVは絶対値で明るさ・符号で暖色/寒色を切り替えます。試作用の初期値で、最終演出ではありません。20%輝度上限は温度保証ではありません。

FAULT、ADC異常・停止、DMA異常で消灯します。WDTや保持された故障状態の後は暗いままにし、通常の完全電源断後は特別な操作なしで起動します。故障でバックアップまで消失すれば再試行し得ます。また独立した5 V正常監視はなく、FAULT通知前の5 V単独低下・復帰は、MCUリセット後の保持方針だけでは捕捉できません。

## 残る実装と実物確認

制御基板の配線・DRC、降圧の配置・ループ、完成コネクタとケーブルの公差、IDCの横向き出口、ジャック/スイッチの荷重とPMMA締付、PETGの造形条件と保持強度を閉じる必要があります。全長の電線モデルには交差や側板との接触が残り、現在の組立STEPは干渉確認用の検討モデルです。固定物が29.8 mm以内に入ることだけでは、全ケーブルを含む30 mmの保証になりません。

Bambuプロジェクトの設定は個別READMEと検証記録に従ってください。保存済みテンプレートがPLAのため、形状確認用の未スライスプロジェクトをPETG用の完成G-codeとして扱いません。
