# Light Block A4 — 前面の全面フロストとJLC部品選定

作成日: 2026-11-06 JST / 2026-11-05 UTC  
状態: **前面加工データと調達設計の改版。完成モジュールの製造リリースではありません。**

## 今回決めたこと

前面は **透明キャストPMMA、2 mm、裏面を文字以外すべて浅く彫刻**する案です。文字の線は元の透明面を残し、Oなどの内部は周囲と同じフロストにします。正面は平滑・光沢のままです。元から曇った板では透明な文字を作れないため、ElecrowのTransparent (000)を希望し、キャスト材であることと仕上げを加工見積り時に確認します。P422のマット材は今回の主案にはしません。[S1,S2]

電子部品はJLCPCB国際PCBAの公開在庫を一型番ずつ確認しました。選定した **29型番・1台あたり76点**は、100台を仮定した実装必要数をすべて上回る在庫がありました。100台は比較用の仮定で、発注数ではありません。余剰実装分、最低購入数、在庫変動、注文時の実装審査は別に扱います。個別の観測日時、価格帯、出典は `procurement_rows.json` と部品表に残しています。

2HPを主案、3HPを予備案に維持します。新しいジャック・スイッチは寸法が変わるため、A3の完成外形をA4の全体干渉確認に流用しません。A4で検証したSTEPは前面板単体です。

## 前面の加工データ

`front_panel/exports/` の `CUT` が切断線、`REAR_FULL_FROST_CLEAR_LETTERS` が裏彫刻です。2HPと3HPの双方があります。裏彫刻ファイルは既に鏡像化しており、再度ミラー・白黒反転しません。黒く塗られた領域を彫り、抜けている文字線を透明に残します。

- 2HP: 9.8 × 128.5 × 2 mm。3HP: 14.9 × 128.5 × 2 mm。
- 選定トグルに合わせた丸穴Ø6.50 mm、ジャック穴Ø6.20 mm。
- 全面とは、正面から見える領域全体です。M2座面やナットの下だけ小さな透明な座面を残します。広い透明な縁やジャック周りの透明な輪は作りません。
- 文字はフォント参照ではなく輪郭です。彫刻領域と文字/穴/座面の重複を検査済み。各幅の彫刻領域は背景1個＋文字内部5個です。
- 図は透明/フロストの配置説明です。白さ、透過率、点灯時のコントラストや均一性を測定・保証したものではありません。

透明文字は透明な窓として見えるため、点灯時はフロスト面との散乱の差が表情になります。常に黒文字のような一定コントラストになるわけではありません。正面までマットな手触りにしたい場合は別の表面処理になりますが、今回は裏彫りの案で進めます。

Elecrowの公開ページは2 mmの透明材と彫刻を扱っていますが、オンライン自動見積りは切断用で、彫刻は個別問い合わせの対象です。今回の細い文字・全面裏彫り・材種・寸法公差の受注確認はまだです。問い合わせや注文は送っていません。[S1]

旧TPS2553DBVR-1の観測在庫は21、先買い可能数は0でした。小ロットの実装が絶対に不可能という意味ではありませんが、継続調達の主案に向きません。選定したTPS2552DBVR-1は2,336個、先買い欄2,329個でした。名称の末尾 **-1（ラッチオフ型）を維持**します。

選定トグルの標準ナットは7.92 mm対辺、9.19 mm対角です。2HPで使える見込みがありますが、大径の標準ロックワッシャや回り止めリングは入りません。スイッチ本体を後部支持体で受ける必要があります。銀接点の低電流動作は統合試作機で確認します。

## LED基板は片面実装の同じ板を2枚

主案は **0.6 mm FR-4を2枚、背中合わせ**です。各板にRGB LED4個、100 nF4個、SH4ヘッダ1個を置き、左右を独立制御します。正面はアクリルのままで、FR-4は内側の細い基板です。ユーザーが好まなかった裸FR-4の前面を採用する変更ではありません。

LEDの両面実装を避けて同一データを反復でき、透明PET FPCの低温実装条件を主案から外せます。透明FPCをJLCが一律に実装できないという意味ではなく、公開サービスはFPC実装を扱います。このPET材とLEDの組合せの実装条件が未確定です。[S3]

| 横断面の仮定 | 寸法 |
|---|---:|
| FR-4板厚 | 0.6 mm × 2 |
| 中央の接着層 | 0.1 mm |
| 外向き部品の予約寸法 | 1.1 mm × 2 |
| 合計 | **3.5 mm** |
| PETG内面間 | 6.4 mm |
| LEDとPETG内面の隙間 | **片側1.45 mm、公称** |

この計算にSH4の相手ハウジングと線の曲げは含みません。ヘッダを同じ高さで両側に置くと必要幅は約7.1 mmとなり、6.4 mmの空間を超えます。下端で位置をずらし、局所的なPETG逃げを設ける設計が必要です。2HPの完成適合をまだ保証できません。

ジャック変更に伴う制御PCB前面Z12.3、厚み1.6、裏面Z13.9を仮定しています。主案の高さ2.0 mmインダクタ＋接合0.1 mmはZ16.0に達します。LED板をZ17〜27へ移すのは干渉を避けるための配置提案です。全体CAD・ピントリム後の寸法・ケーブル・電源変換PCBを含めた30 mm条件は未検証です。

## 部品を安くする方法と費用

抵抗・コンデンサは13型番をすべてBasicで揃えました。100 nFはC14663に統一、68.1 kΩは在庫の多い68 kΩへ変更します。LDOの1 µF入力/出力コンデンサは4.7 µFに増やし、MCUバルクと型番を統一します。DCバイアス後の実効容量の確認は別に必要です。

CV変換の82 kΩは1%品を採用する設計変更です。抵抗6個だけの最悪組合せ計算では、±5 V入力で最大約0.233 Vの入力換算誤差になります。照明強度を扱う機器として許容し、ゼロ点/ゲインのFW補正を入れる方針です。ADC、アンプ、温度、漏れの誤差を含む精度保証ではありません。公称式は `VADC = V3V3/2 + CV/8`、検出枝は20 MΩ、THRUは受動直結です。

ケーブルは数値在庫を確認できたDigiKeyの価格を主計算に使用しています。Adafruit直販は100本以上で$0.76と安いものの、数値在庫が非公開なので、DigiKeyの在庫と組み合わせて計算しません。10台時の実装部品＋上記3本のケーブルは$14.6945/台、100台時は$11.9565/台です。[S14,S15]

これは**実装する数量に価格帯を当てた算術**です。余剰部品、最低購入数、別PCB注文への数量分割、PCB製造、SMT/THT実装、段取り、治具、X線検査、書込み、電源ケーブル、外装、送料、税は含みません。完成品の価格や発注見積りではありません。

WS2812B-2020-V6 / C52917434は **Standard Only / High difficulty / MSL5** と掲載されています。基板をFR-4へ変えてもこの部品指定は変わりません。StandardではBasicとExtendedの両方にフィーダー費があり、Basic化だけで段取り費をゼロにはできません。型番数の統一と片面LED基板化を優先します。[S4,S5]

JLC公式の2026-10-22更新表ではStandardの段取り＋ステンシルは片面$33.77、両面$67.54。異種面付けは追加設計数あたり片面$25.56、両面$51.12です。受動電源変換PCBを制御PCBと同じパネルに含める案は、必ず別注文との見積りを比較します。無料で3種類を一緒に組める前提にはしません。[S5]

Würthインダクタは$1.5814（10個帯）と高めですが、現状の高さ2 mmを保てて、438個の在庫があります。安いSunlord SWPA4030S2R2NT / C279948は約$0.0589ですが、2.2 µH・高さ3 mmとなり、配置とリップルが変わります。今回は代替案として記録し、主案を安価品に無条件で置換しません。PMEG4010CEJも漏れと外形を保つため主案に残します。

## 家で必要な組立と工場の範囲

JLCは基板のSMTと指定PTH部品を実装する前提です。カタログのWave Soldering部品は、FAQ上、工場側の手はんだ対象です。個別部品の実装方法、トリム、基板支持、回転角はBOM/CPLと実装審査で確定します。[S6]

ケーブルは差し込み式の完成品を別手配します。LED用はAdafruit4399、50±5 mmを2本/台。DigiKey1528-4399-NDの直接観測は12,957本でした。電源はMolex151340300（DigiKey表記0151340300）、50±6 mmを1本/台。DigiKeyWM15252-NDの直接観測は17,783本でした。両方とも100台分の数量を上回ります。DigiKey在庫をJLC在庫とは混同しません。MolexはA1→B3/A2→B2/A3→B1の結線なので、変換PCBの銅配線で反転を補償します。JLCが別売ケーブルまで完成ハーネスとして納品するとは扱いません。[S7,S8,S14,S15]

追加調査は `harness_supply_followup.md/.json` にあります。先に確定した `io_service_audit` の「数値在庫未確認」は観測当時の状態で、ケーブルの現在の選定根拠はこの追加資料と統合部品表を優先します。

自宅ではPETGを造形し、基板・パネルをねじ止めし、完成ケーブルを差し込む構成を目指します。追加の光学専用PCBを先に発注する計画はありません。完成した統合試作を一度発注し、その機体でPETG厚さ/プリント条件、白色発熱、CV応答と光の広がりを確認します。

## 次に設計上閉じる項目

1. 新ジャックの挿抜荷重を受けるPETG支持体、トグルの座面と回り止め、SH4端子の逃げ、電源アダプタの固定を含む全体CAD。
2. 正確なフットプリントでネイティブKiCad回路図・実配線。ADC負側クランプ/電源OFF、逆接、DCバイアス容量、buckループの確認。
3. ERC/DRC、製造BOM/CPL、面付け、Gerber、工場書込み用HEX/BINと検査手順。SWDのサービスパッドは残す。
4. 部品在庫の再照合と具体的なJLC見積り、Elecrowの材種/裏彫刻見積り。これらは未送信。
5. 統合試作機で挿抜、温度、CV −5/0/+5 V、THRU、3モード、点灯均一性と隣のKumiko照射を確認。

今回の検証は前面の形状/彫刻ブール演算、29型番の公開在庫、価格帯算術、抵抗誤差の計算です。PCBやFWの動作試験、最終DFM、30 mm全体収まりは完了していません。
